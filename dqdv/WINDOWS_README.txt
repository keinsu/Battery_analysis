dQ/dV Cycling — Windows 64-bit

1. ZIP 파일 전체를 원하는 폴더에 압축 해제합니다.
2. DQDVAnalyzer.exe를 실행합니다.
3. 자동으로 열리는 브라우저에서 CSV를 선택합니다.
4. 분석이 끝나면 dQ/dV Cycling 실행 창을 닫습니다.

Python 설치는 필요하지 않습니다. EXE 옆의 _internal 폴더를 함께 보관하세요.
EXE만 따로 복사하면 실행되지 않습니다. 인터넷 연결 없이 로컬에서 분석합니다.
브라우저가 자동으로 열리지 않으면 실행 창의 '분석 화면 열기'를 누르세요.

Cycle 예: 1,5,10-50:5 또는 전체
마우스: 좌표 표시 / 휠: 확대 / 드래그: 확대 또는 이동
더블클릭: 초기화 / 범례 클릭: 표시·숨김
