# Battery Analysis Suite v0.7.1

`BatteryAnalysisSuite-Desktop.exe` 하나를 다운로드하고 실행합니다. Python 설치, 브라우저, 웹 서버, 별도 _internal 폴더가 필요하지 않습니다. 첫 실행 시 분석 프로그램 선택 화면이 나타나며, 포함된 런타임을 임시 폴더에 푸는 동안 잠시 걸릴 수 있습니다.

1. 시작 화면에서 `dQ/dV Analyzer`, `Step dQ/dV Analyzer`, 또는 `사이클분석`을 선택합니다. `dQ/dV Analyzer`는 Cycle 변화 분석이고, `Step dQ/dV Analyzer`는 충전 Step·방전 Step을 각각 지정하는 한 사이클 분석입니다. 사이클분석은 다음 확장 작업 공간입니다.
2. dQ/dV Analyzer에서 CSV 열기를 누르고 파일을 선택합니다.
3. 두 파일을 비교하려면 `비교 CSV 추가`를 눌러 파일 B를 선택하고, 왼쪽의 비교 채널·비교 Cycle을 설정합니다. 파일 A는 진한 파랑→연한 파랑→연한 빨강→진한 빨강, 파일 B는 진한 검정→연한 검정→연한 보라→진한 보라로 cycle 순서에 따라 표시됩니다. 충전은 실선, 방전은 점선입니다.
4. 열과 단위를 확인합니다. 전압은 V/mV/µV를 실제 숫자 크기로 먼저 자동 추정하고 열 이름은 보조로 사용합니다. 읽어들인 열과 적용 단위는 파일명 옆에 표시됩니다. 필요하면 왼쪽 설정을 바꾸고 열·단위 적용을 누릅니다.
5. Cycle에 `1,5,10-50:5` 또는 `전체`를 입력하고 충전/방전 방향을 선택합니다.
6. 조건 적용 / 분석을 누릅니다.
7. `그래프` 탭에서 선택 cycle의 dQ/dV와 dV/dQ를 나란히 봅니다. 각 지표에서 충전은 위쪽, 방전은 아래쪽 패널에 분리됩니다. 원본 V–Q는 `원본 V–Q 보기`를 눌러 필요할 때만 펼칩니다. `단일 Cycle 상세` 탭에서도 dQ/dV와 V–Q를 충전(위)·방전(아래)으로 나누고 파일 A/B의 Cycle을 각각 선택해 비교합니다. `피크 전압 추이` 탭에서는 선택 cycle의 Cycle–Peak voltage 점 그래프를 봅니다.
8. 마우스를 그래프 위로 이동하면 가까운 데이터점의 cycle·전압·dQ/dV 좌표와 십자선을 봅니다.
9. 휠로 확대/축소, 드래그 이동 또는 영역 확대, 전체 범위 버튼으로 초기화합니다.
10. 곡선 CSV, 피크 CSV, 분석 설정 JSON, 그래프 PNG를 저장할 수 있습니다.

`Step dQ/dV Analyzer`에서는 Cycle 선택 대신 `충전 Step`, `방전 Step`을 각각 입력합니다. 파일을 열면 충전·방전별 전류 절댓값의 중앙값이 가장 작은 Step을 자동 입력하며, 동률이면 데이터에서 가장 나중에 나온 Step을 선택합니다. 비교 파일 B에도 같은 기준을 적용합니다. Step 열을 자동으로 찾지 못하면 `열 · 단위 설정 보기`에서 Step 열을 지정해야 합니다.

왼쪽의 선택 목록과 수치 입력은 마우스 휠로 값이 바뀌지 않습니다. 열·단위 설정은 `열 · 단위 설정 보기`를 눌러 필요할 때만 펼칠 수 있습니다. 여러 cycle을 선택하면 초기 cycle은 파랑, 마지막 cycle은 빨강으로 표시되며 중간 cycle도 청록·녹색·노랑 계열로 구분됩니다.

여러 cycle에서 피크 전압 추이 그래프를 표시할 때의 데이터 인덱스 오류를 수정했습니다.

Cycle 입력칸 아래에 현재 분석 채널에서 추출된 전체 cycle 수와 시작·마지막 cycle 번호가 표시됩니다.

그래프 탭의 좌표·상태 표시 영역은 한 줄 높이로 유지되며 남는 세로 공간은 그래프에 사용됩니다.

다수 cycle을 선택하면 그래프 상단에 시작·끝 cycle 번호가 붙은 그라데이션 막대가 표시됩니다. 파일 A는 파랑→빨강, 파일 B는 검정→보라 계열이며 충전은 실선, 방전은 점선입니다.

dQ/dV와 dV/dQ는 모두 위쪽 peak와 아래쪽 valley를 검출합니다. 그래프에서 ○는 peak, ×는 valley입니다. 피크 표와 피크 CSV에는 `metric`(dQ/dV 또는 dV/dQ), `kind`(peak 또는 valley), 축 좌표와 미분값이 저장됩니다.

자동 열 매핑은 `Voltage(mV)`·`Voltage(uV)` 등 실제 전압 열을 우선 선택하며 `DataSequence` 같은 순번 열을 전압으로 사용하지 않습니다. 전압 단위 자동 판정은 데이터 크기와 열 이름이 충돌할 경우 데이터 크기를 우선합니다. 자동 선택이 맞지 않으면 `열 · 단위 설정 보기`에서 전압 단위를 직접 바꾼 뒤 다시 적용할 수 있습니다.

계산은 첨부 원본 dqdv.py를 변경 없이 호출합니다. 기본 500포인트, Savitzky–Golay 21포인트/3차, 두 번 스무딩, 상한전압 기반 CV 제외, 피크 민감도 3%입니다. 입력 장비별 CSV 파서는 기존 Qt 프로그램 전체를 복제한 것이 아니며 열·단위 확인이 필요합니다.

여러 step의 용량 리셋은 원본 계산 로직처럼 합산하지 않습니다. 구간/품질 탭과 원본 V–Q도 확인하세요. 대용량 CSV 로드와 다수 cycle 계산 중에는 창이 잠시 응답을 기다릴 수 있습니다.

개발: Python 3.12에서 requirements-native.txt 설치 후 `python native_app.py`.
빌드: `python -m PyInstaller --noconfirm --clean native.spec`.
검증: `python verify_native.py dist/BatteryAnalysisSuite-Desktop.exe`.
