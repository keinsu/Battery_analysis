Outlook Mail Finder v0.2 — Classic Outlook / Windows
====================================================
1. OutlookMailFinder.exe 압축을 해제합니다.
2. 회사 보안 정책상 외부 프로그램 및 Outlook COM 접근을 허용하는지 확인하세요.
3. 클래식 Outlook을 먼저 실행하고 EXE를 더블클릭하세요.
4. 메일함을 선택하고 [선택한 메일함 색인]을 누르세요.
5. PST가 목록에 없으면 [기존 PST 연결]로 PST 파일을 연결할 수 있습니다.
6. 색인 완료 후 제목/발신자/수신자/첨부파일명, 선택적으로 본문을 검색하세요.
7. 검색 결과 더블클릭 시 원본 메일을 Outlook에서 엽니다.

유의사항
- 원본 메일은 수정/삭제하지 않습니다. 그러나 PST 연결은 Outlook 프로필을 변경합니다.
- 검색 DB: %LOCALAPPDATA%\OutlookMailFinder\mail_index.sqlite3
- 데이터베이스에는 제목, 주소, 첨부 이름이 암호화되지 않은 형태로 저장되며, 본문 검색 체크 시 본문도 저장됩니다.
- 회사 파일을 GitHub에 업로드하지 마세요. 빌드에는 공개 프로그램 소스만 포함됩니다.
- 검색 누락 가능성을 확인하도록 색인 오류 건수를 표시하지만, 모든 메일 색인을 보장하지 않습니다.
- 현재 EXE는 Windows 빌드 및 자체 테스트를 통해 확인하며 Outlook 실메일함 연동은 회사 PC에서 별도 검증이 필요합니다.
